# Smart Campus Application

A Java Swing desktop application designed for smart campus management.

---

## Features
* **User Authentication:** Login system for Students and Admins.
* **Campus Dashboard:** Interactive graphical user interface (GUI) built with Java Swing.
* **Data Management:** Real-time updates and structured data handling.
