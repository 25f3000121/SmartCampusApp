# Smart Campus Application

A Java Swing desktop application designed for smart campus management.

---

## Features
* **User Authentication:** Login system for Students and Admins.
* **Campus Dashboard:** Interactive graphical user interface (GUI) built with Java Swing.
* **Data Management:** Real-time updates and structured data handling.

---

## How to Run the Application

### Option 1: Download Executable (Recommended)
1. Go to the **[Releases](../../releases)** section on the right sidebar.
2. Download the `KISHORE_R.jar` (or `.zip`) file from the latest release.
3. Ensure you have **Java 17 or higher** installed on your computer.
4. Double-click the downloaded file to launch the application directly.
